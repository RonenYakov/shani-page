┌──────────────────────────────────────────────────────────────────────────────┐
│                        ⚡ QUICK START (30 MINUTES)                           │
└──────────────────────────────────────────────────────────────────────────────┘

   STEP 1: Install FFmpeg (5 min)
   ├─ Windows: choco install ffmpeg
   ├─ Mac: brew install ffmpeg
   └─ Linux: sudo apt install ffmpeg

   STEP 2: Convert Videos (10 min)
   ├─ cd scripts
   ├─ Run conversion script for your OS
   └─ Wait for conversion to complete

   STEP 3: Update Hero Video (5 min)
   ├─ Open src/components/HeroWorking.tsx
   ├─ Change preload="metadata" → preload="none"
   └─ Update video sources to optimized versions

   STEP 4: Add Resource Hints (2 min)
   ├─ Open index.html
   └─ Add preconnect/preload tags

   STEP 5: Update Vite Config (3 min)
   ├─ Open vite.config.ts
   └─ Add code splitting configuration

   STEP 6: Test & Deploy (5 min)
   ├─ npm run build
   ├─ npm run preview
   ├─ Run Lighthouse audit
   └─ Deploy if happy with results ✅

   RESULT: 50-70% improvement! 🎉

┌──────────────────────────────────────────────────────────────────────────────┐
│                        🎯 KEY IMPROVEMENTS                                   │
└──────────────────────────────────────────────────────────────────────────────┘

   1. VIDEO OPTIMIZATION
      • Convert .mov → WebM + MP4
      • Reduce file sizes by 60-80%
      • Create poster images

   2. LAZY LOADING
      • Videos load only when needed
      • Pause when scrolled away
      • Save bandwidth & CPU

   3. HERO VIDEO
      • Defer loading
      • Use optimized formats
      • Add poster image

   4. CODE SPLITTING
      • Smaller initial bundles
      • Faster first load
      • Better caching

   5. RESOURCE HINTS
      • Preconnect to fonts
      • DNS prefetch
      • Faster connections

   6. MOBILE OPTIMIZATION
      • Detect slow connections
      • Skip videos on 2G/3G
      • Better battery life
